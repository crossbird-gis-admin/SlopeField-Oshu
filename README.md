# 奥州市傾斜計測アプリ（Cross Bird GIS）

1m DEM を使って、地図上で**囲んだ範囲(農地など)の傾斜**と、**引いたラインの勾配・断面**を計測するWebGISです(GitHub Pagesで動作)。
DEMはこのPCのローカルファイルを読み込み、計算はすべてブラウザの中で行います(データはどこにも送信されません)。
描いた範囲・ラインと計測結果は、作業フォルダに GeoJSON と CSV で自動保存されます。

## フォルダ構成(リポジトリ)

```
index.html               地図本体(冒頭の CONFIG だけ編集すればOK)
README.md
data/area.geojson        対象区画(1,113区画、計算結果つき。起動時に表示)
data/dem1m_??.tif        1mDEM(対象区画の周り20mだけ、14枚)
data/oshu_5m_r?c?.tif    奥州市付近の5mDEM(6枚のタイル。1mの無い所と、区画の外の計測に使う)
data/rcom.geojson        農業集落界(DEMの範囲にかかる724集落。起動時に表示)
tools/serve.py           ローカル確認用サーバー
tools/dem_tiles.py       DEMをGitHubに載せられる大きさのタイルに分ける
tools/fgd_dem5_merge.py  基盤地図情報の5mDEM(XML)を、5A優先・5Bで穴埋めして1枚のGeoTIFFにする
tools/make_rcom.py       農業集落境界のGPKGから、DEMの範囲にかかる集落を取り出す
tools/fgd_dem1_tiles.py  基盤地図情報の1mDEM(ダウンロードzipのまま)を、2次メッシュごとのGeoTIFFにする
tools/clip_dem_area.py   1mDEMを区画の周りだけに切り詰めて、GitHubに載せられるタイルにする
tools/make_area.py       区画のGeoPackageを、アプリで読むGeoJSONにする
```

## 対象区画(area.gpkg)

- 区画(1,113)を起動時に表示。地区(T1)で色分け、ズーム15以上で団地名(T2)を表示
- **区画をクリック** → 属性と計算結果(全体の傾き・平均傾斜・傾斜区分の割合・標高・表面積・直払の目安)。あらかじめ全区画を計算して `area.geojson` に入れてあるので、すぐ出ます(「計算し直す」でその場で再計算)
  - **既存の平均傾斜との比較**:属性の `平均傾`(1/n の n)・`平均_1`(度)と、DEMで求めた全体の傾き(1/n・度)を並べて表示
  - **1mDEMで計算した割合**も表示(残りは5mDEM)
- **選択**:Ctrl(またはShift)+クリックで選択/解除(黄色の太線)。右パネル上の「対象区画の選択」で
  - 表示範囲を選択・すべて選択・選択へ移動・解除。レイヤ欄の地区の横の「選択」で、その地区をまとめて選択
  - 「クリックで選択する」にチェックすると、普通のクリックで選択/解除(スマホ・タブレット向け)
  - **「選択した区画をCSVで書き出し」**:元の属性+計算結果+中心の緯度経度。作業フォルダを開いていればそこに保存、なければダウンロード
  - 選択はこのブラウザに記憶されます(次に開いても残る)
- 計測ツール(範囲・ライン)はそのまま使えます

### 計算に使ったDEMと結果のまとめ(2026年10月)

| | 区画数 |
|---|---|
| 1mDEMだけで計算 | 633 |
| 1mと5mの組み合わせ | 313 |
| 5mDEMだけ(1mが無い) | 126 |
| DEMなし(5mの範囲外。未ダウンロードの2次メッシュ 584037・584047・584057・584130 にかかる) | 41 |

- 1mが無い区画は、1mが整備されていない所(584161・584150 など)と、未ダウンロードの2次メッシュの所。1mや5mを追加したら、`tools/clip_dem_area.py` で作り直し、アプリで「全地物を計算し直す」→ レイヤの「書き出し GeoJSON」を `data/area.geojson` に置き換える
- **既存の平均傾斜(平均傾)との比較**(DEMが95%以上ある963区画):DEMによる**全体の傾き**(平面近似)との相関0.77、差の中央値 −0.18°、差の大きさの中央値 0.72°。セルごとの平均傾斜は法面を含むため3.5°ほど大きく出る。田の基準(1/20・1/100)の区分の一致は708/963
- 検証:1mだけの区画をPython(numpy)で計算し直し、全体の傾きは0.02°以内、平均傾斜は0.1°以内で一致

## 1mDEMを使う(ローカル)

1mDEMは量が多い(奥州市付近の11メッシュで約670MB)ので、GitHubには載せず、自分のPCで作業フォルダに入れて使います。

1. 基盤地図情報から1mメッシュ(DEM1A)をダウンロード(zipのままでよい。QGISのプラグインは、中にzipが入ったzipやメタデータのXMLがあると「Incorrect XML file」で止まります)
2. `python tools/fgd_dem1_tiles.py ダウンロードした.zip 1m`
   → `1m/oshu_1m_<2次メッシュ>.tif`(平面直角X系・1m、標高はcm単位の整数)。メモリや時間が足りないときは `python tools/fgd_dem1_tiles.py ダウンロードした.zip 1m 6678 all half` で南北に分けて作る。途中で止まっても同じコマンドで続きから
3. アプリの「作業フォルダを選ぶ」で 1m フォルダを選ぶ(または「DEMを追加」でtifを選ぶ)
   - **1mのある所は1m、1mの無い所は公開版の5m**で計算します。範囲の統計はセルの面積で重み付けしているので、1mと5mが混ざっても面積どおりの値になります
   - QGISでもそのまま開けます(GDALのスケール付きなので標高はm表示)

## 農業集落界

- 農林水産省の農業集落境界(survey-map の `data/2025.gpkg` の `rcom` レイヤ、岩手県全域)から、DEMの範囲にかかる **724集落**(奥州市459・北上市79・一関市73・金ケ崎町64 ほか)を取り出したもの。属性は 集落名・よみ・旧市町村・市町村・集落コード・面積_ha
- 白い線で表示し、ズーム15以上で集落名を表示。境界は0.5mで単純化(面積の差は0.1%未満)
- **集落ごとの傾斜**
  - 地図の集落の中をクリック → 地点の標高・傾斜の下に「〇〇(旧村名)」が出るので、「この区画の傾斜を計算」で集落全体の全体の傾き・平均傾斜・傾斜区分の割合などを表示。「計測に追加」で計測一覧に入れて保存
  - 右パネルのレイヤ欄「全地物の傾斜を計算」で全集落を一括計算(30秒ほど)→「書き出し CSV / GeoJSON」で集落ごとの傾斜の表
- 集落界は塗りなし(線だけ)なので、中をクリックしても地点の傾斜が見られます。表示の設定は `CONFIG.layers`(`label`=ラベルの列、`fill:false`=塗りなし、`color`=線の色)
- 作り直すとき:`python tools/make_rcom.py 集落界.gpkg DEM.tif data/rcom.geojson`

## 奥州市付近の5mDEM(data フォルダ)

- 基盤地図情報 数値標高モデル 5mメッシュ。**5A(航空レーザ)を優先し、5Aに無い所を5B(写真測量)で補完**(15の2次メッシュ、5840-47・57、5841-40〜42・50〜53・60〜63・71・72)
- 平面直角座標 X系(EPSG:6678)・5m。標高は **cm単位の整数**で保存(GDALのスケール 0.01 付きなので、QGISでもmで表示されます)
- GitHubのWebアップロード(1ファイル25MBまで)に収まるよう6枚に分割。境目は2セルずつ重ねてあるので、タイルをまたぐ範囲・ラインも1枚のときと同じ値になります(検証:標高差 最大5mm、傾斜差 最大0.05°)
- 北上山地の一部の山林は5A・5Bとも無いので空白です(川・ため池の水面も空白)
- 1mDEMを持っている所は、作業フォルダや「DEMを追加」で1mを読み込めば、そちらが優先されます

### DEMを作り直す・別の地域にするとき

1. 基盤地図情報から5mDEMをダウンロード(zip)。中のzipのXMLを1つのzipにまとめるか、5A・5Bに分けたzipを用意
2. `python tools/fgd_dem5_merge.py 5Aのzip 5Bのzip 出力フォルダ` → 平面直角X系の1枚のGeoTIFF(別の系にするときはスクリプト中の 6678 を変更)
3. `python tools/dem_tiles.py 1枚のGeoTIFF data/名前` → タイルができ、`CONFIG.dems` に書く行が表示される
   (必要なもの:`pip install numpy tifffile imagecodecs pyproj`)

## 基本の使い方:地域ごとの「作業フォルダ」

1. PCに地域ごとのフォルダを作り、次のファイルを入れる
   - **DEM**:GeoTIFF(`.tif`)。何枚でも可(隣り合うメッシュを分けたままでOK)
   - **レイヤ**(任意):圃場の区画(ポリゴン)や農道(ライン)の `.gpkg` / `.geojson`
2. 右パネルの「**作業フォルダを選ぶ**」でそのフォルダを選ぶ(ブラウザの確認で「編集を許可」)
   - DEMとレイヤが自動で読み込まれ、その場所へ移動します
3. 範囲を囲む・ラインを引く(下記)
4. 計測は同じフォルダの `傾斜計測.geojson`(本体)と `傾斜計測.csv`(Excel用)に自動で上書き保存されます
5. 次に開いたときは「**前回のフォルダを開く**」で続きから。別の地域は「別のフォルダに切替」

```
例)C:\傾斜計測\箕輪_ほ場A\
      dem_5337xxxx.tif        ← DEM
      筆ポリゴン.gpkg          ← レイヤ(任意)
      傾斜計測.geojson         ← アプリが作る(描いた範囲・ライン+結果)
      傾斜計測.csv             ← アプリが作る(同じ内容の表、WKT列に形状)
      断面_北側の農道.csv      ← 断面を保存したとき
```

作業フォルダは Chrome・Edge で使えます。Firefox・Safari では「DEMを追加」「レイヤを追加」でファイルを選び、計測は「GeoJSON / CSV で保存」でダウンロードしてください。
DEMやレイヤは地図にドラッグ&ドロップしても読み込めます。

## 範囲の傾斜(五角形・四角ボタン)

範囲を囲むと、セル中心が範囲内にある1mセルについて次を計算します。

| 項目 | 内容 |
|---|---|
| **全体の傾き** | 範囲内の地表を**1枚の平面で近似**したときの傾き(度・%・1/n)と、低い方の向き(16方位)。棚田のように平らな田面と急な法面が混ざる所では、セルの平均よりこちらが「ほ場の勾配」に近い |
| 平面近似残差 | 平面からの標高のばらつき(標準偏差, m)。大きいほど段や凹凸があり、全体の傾きは目安になる |
| 平均・中央値・90%点・最大・最小・標準偏差 | セルごとの傾斜(Horn法・3×3)の統計 |
| 傾斜区分の割合 | 3°未満/3〜8°/8〜15°/15〜20°/20〜30°/30°以上 の面積割合(`CONFIG.slopeClasses` で変更) |
| 標高 | 最高・最低・平均・標高差 |
| 投影面積・表面積 | 表面積 = 投影面積 × 平均(1/cosθ)(RichField と同じ計算) |
| 直払の目安 | 全体の傾きを中山間地域等直接支払の傾斜基準に当てはめたもの。田:1/20以上=急傾斜、1/100以上=緩傾斜/畑・草地:15°以上=急傾斜、8°以上=緩傾斜(`CONFIG.chokubarai`)。**実際の判定方法は市町村・県の要領に従ってください** |

## ラインの勾配・断面(折れ線ボタン)

ラインを引くと、0.5m間隔で標高を取り(双一次補間)、次を計算します。ポップアップに断面図が出ます。

| 項目 | 内容 |
|---|---|
| **平均勾配** | 始点と終点の標高差 ÷ 水平距離(度・%・1/n) |
| 最大勾配 | 10m以上離れた2点の間の勾配の最大(`CONFIG.gradWindow`)。断面図に赤で表示。DEMの細かな凹凸を拾いすぎないよう区間で見ています |
| 線上の地表の傾斜 | ラインが通るセルの傾斜(Horn法)の平均・最大。ラインの向きに関係ない地表面そのものの傾き(等高線に沿った農道でも、法面の傾斜がわかる) |
| 水平距離・斜距離 | 斜距離は断面に沿った長さ |
| 標高 | 始点・終点・標高差・最高・最低、累積の上り・下り |

「断面をCSVで保存」で、距離・経度・緯度・標高・地表の傾斜・前の点からの勾配の表を、作業フォルダ(なければダウンロード)に保存します。

## そのほか

- **地点の標高・傾斜**:地図をクリックすると、その地点の標高・傾斜・勾配・向きを表示(DEM欄のチェックで切替)
- **傾斜区分図**:表示範囲の傾斜を区分ごとに色分けして重ねます(ズーム14以上。動かすと描き直し)。背景の「地理院 傾斜量図」も比較に使えます
- **レイヤ**:区画やラインをクリック →「傾斜を計算」「計測に追加」。「全地物の傾斜を計算」で一括計算し、元の属性+結果を CSV / GeoJSON で書き出し。列の値で色分け・ラベル表示もできます(RichField と同じ)
- **計測の受け渡し**:`傾斜計測.geojson` を渡し、受け取った人は「他の計測ファイルを読み込む」で追加(同じ計測は更新日時の新しい方が残ります)。保存ファイルから読んだラインの断面図は、DEMがあれば開いたときに作り直します

## DEMについて

- 座標系はGeoTIFFから自動で判定します(JGD2011/JGD2000 の平面直角座標 I〜XIX系、UTM 51〜55帯、緯度経度)。判定できないときはEPSGコードか系番号を聞かれます(長野県は VIII系 = 8)
- 黄色の点線がDEMの範囲です。範囲外では傾斜を計算できません(面積・距離だけ出ます)
- 1回に計算できる大きさは約800ha(1mDEM)まで(`CONFIG.maxCells`)
- **5mDEMも使えます**(セルの大きさはGeoTIFFから読みます)。1mと5mを両方入れると、重なる所は細かい1mを使い、1mの無い所(歯抜けのタイル)だけ5mで補います。傾斜区分図も同じです
  - 5mDEMでは、畦畔の法面のような幅の狭い急斜面がならされ、最大傾斜や急傾斜の割合は小さく出ます。ほ場全体の傾き(平面近似)やラインの平均勾配への影響は小さいです
  - ラインの最大勾配を見る区間(`CONFIG.gradWindow`)は、5mDEMに合わせて 10 m にしています
- 基盤地図情報の1mDEM(XML)は、QGISのプラグイン(QuickDEM4JP など)でGeoTIFFに変換し、平面直角座標にしておくのがおすすめです

## 計算方法と検証

- 傾斜:Horn法(3×3)。緯度経度のDEMは、範囲の中心緯度でセルの大きさをmに直して計算
- 全体の傾き:範囲内のセル中心(x=東, y=北, m)と標高に z = a·x + b·y + c を最小二乗で当てはめ、傾き = atan(√(a²+b²))
- 検証(合成DEM)
  - 10°・南東向きの平面:全体の傾き 10.00°、方位 135°、平均 10.00°、面積比 1.0154(= 1/cos10°)。南東へ100mのライン:勾配 10.00°、等高線方向:0°
  - 2°・西向きの平面:全体の勾配 3.49%(1/28.6)、直払の目安 田=緩傾斜・畑=基準未満
  - 合成棚田(畦畔検出マップのサンプル):Python(numpy)で計算した値と一致(平均 3.21°、中央値 0.7°、最大 30.46°、面積比 1.0092、平面近似 2.27°・南向き、3°未満 80.6%)

## 公開・ローカル確認

1. GitHubで新しいリポジトリ(例 `SlopeField`、Public)を作り、`index.html`・`README.md`・`data`・`tools` をアップロード(Webの「Add file → Upload files」にフォルダごとドラッグ。dataのタイルは1枚25MB未満なのでWebから上げられます)
2. 「Settings」→「Pages」→ `main` / `/(root)` →「Save」
3. ローカルで確認:`python tools/serve.py` → `http://localhost:8000`

DEMを使わずにローカルのファイルだけで使うなら、`CONFIG.dems` を `[]` にして `data` を消します。
